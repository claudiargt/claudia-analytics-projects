# 🎼 STAYING IN THE QUEUE: Which Spotify Users Are Most Likely To Leave...and How to Keep Them

## Project Overview
This project analyzes user behavior data to identify patterns associated with customer churn in a music streaming context. The goal was to understand how engagement metrics relate to user retention and to evaluate whether behavioral signals can help predict churn.

The project was completed as part of BANA 205: Foundations of Marketing at UC Irvine’s Paul Merage School of Business.

## Research Questions
- Which user engagement behaviors are most strongly associated with churn?
- Can behavioral data be used to predict churn risk?
- How can insights from churn modeling inform marketing and retention strategies?

## Data & Methods
- Data: Synthetic Spotify-style user dataset provided for academic analysis
- Exploratory Data Analysis: Examined listening frequency, session behavior, skips, and engagement intensity to identify churn-related patterns
- Feature Engineering: Created engagement-based features capturing usage frequency, consistency, and interaction depth
- Models Used:
  - Logistic Regression (baseline, interpretable model)
  - Tree-based classification model to capture nonlinear behavior patterns
- Evaluation: Model performance assessed using accuracy and classification metrics

## Key Insights
- Lower engagement frequency and inconsistent usage patterns were strongly associated with churn
- Simple, interpretable models provided actionable insights for identifying at-risk users
- Behavioral features can support targeted retention and lifecycle marketing strategies
