# 🎓📱 CAUGHT IN THE ALGORITHM: Predicting Academic Performance from Social Media Addiction Patterns

## Project Overview
The goal was to explore which behavioral signals, if any, help explain variation in academic outcomes and how these insights could inform student support strategies. The project applies exploratory analysis and classification models to assess predictive patterns rather than causal claims.

## Methods
- Exploratory data analysis of student demographics, study habits, and social media behavior
- Supervised classification models, including logistic regression and tree-based approaches
- Model evaluation using standard performance metrics and comparative analysis

## Key Insights
- Engagement and time-use patterns were more informative than raw platform usage alone
- Feature engineering and preprocessing had a significant impact on model performance
- Results suggest social media behavior should be interpreted contextually, not as a single negative indicator
